## 一、节奏原则

1. **文档先行**：任何界面改动先在 `docs/` 写下意图与验收，再改代码；完成后回写版本表。
2. **单一数据源**：图谱数据只来自 `static/docs-graph.json`（由 `tools/gen_docs_graph.py` 生成），经典图谱与 AXON 不各自维护数据。
3. **每次改动可验证**：每个版本至少留下 1 张截图 + 1 组数字（节点数、关系数、帧率、溢出量等）。
4. **回滚成本低**：新能力优先“增强层”（独立 js/css），原脚本尽量不改；改 HTML 仅追加引用行并留 `.bak`。

## 六、决策台（2026-10-29）

### 背景：面板数据为空的真正根因

盘前/盘后经常看到「K线数据不可用」「暂无数据」「资金流取数失败」——不是数据源没数据，而是
**服务端 Python 的 urllib 读取了 Windows 系统代理**（当时系统代理指向本机 sing-box / Clash）。
行情请求经代理转发后本地端口拒绝连接（WinError 10061），腾讯 / 东财 / AkShare 全部超时。

修复：`server/main.py` 启动最前面设置 `NO_PROXY=*` / `no_proxy=*`，让行情与资讯数据源直连；
浏览器仍走系统代理访问境外站点，互不影响。修复后实测恢复：日K、分时、多股报价、大盘概览、
市场仪表盘、个股资金流、板块资金流、市场要闻、热门股、龙虎榜、板块排行全部返回真实数据。

### 新增工作区：决策台（decision-desk.js + decision-desk.css）

一屏完成「盘前决策 → 盘中纪律 → 盘后复盘」，全部复用现有只读 API：

| 卡片 | 数据来源 | 作用 |
|---|---|---|
| 今日决策结论 | /api/market-dashboard + /api/global/linkage + /api/automation/risk/health | 加权计算风险指数（0–100），给出进攻/均衡/防守结论与建议仓位上限，列核心理由 |
| 世界局势 / 隔夜外盘 | /api/global/assets + /api/global/linkage | 美股/亚太/大宗/外汇与全球联动评分（利空/利多） |
| 市场温度 | /api/market-dashboard | 涨跌分布、涨跌停、成交额、中位涨跌、主要指数 |
| 资金流向 / 板块强弱 | /api/market-dashboard.sectors + /api/market/north | 强势板块（可点击跳转策略选股）、北向结构、披露状态 |
| 持仓与风险 | /api/automation/positions + /api/automation/risk/health | 权益/现金/持仓市值、风控体检未通过项 |
| 事件情报 / 世界局势 | /api/brain/intel + /api/news/market | 情报风险分、AI 简报、要闻与观察点 |
| 盘后复盘摘要 | /api/review/summary + /api/review/weekly | 权益、区间/超额收益、最大回撤、闭合交易/胜率、流程可追溯 |
| 决策卡 / 交易计划 | 本地自动检查 + localStorage | 8 项自动检查（外盘/宽度/涨跌停/成交额/资金/风控/事件/仓位纪律）、生成计划文本、保存、复制、历史回看 |

交互约定：

- 阶段自动识别（09:25 前盘前、15:00 前盘中、之后盘后），也可手动切换并记忆；
- 板块行点击 → 跳到「策略选股」并切换板块；各卡右上角可跳「大盘纵览 / 自动化中心」；
- 60 秒自动刷新（仅视图可见时）；顶部显示数据质量与更新时间；
- 数据缺失时显示降级状态而不是空白。

### 验收

- 决策台 8 张卡片全部渲染、无控制台错误；模式切换/保存计划/历史/板块联动实测通过；
- 体检 `python tools/check_data_sources.py` 40/40 PASS；
- 已知数据源限制：60 分钟 K 线源暂无数据；北向资金 2024-08 起不再实时披露；部分时段板块资金流接口降级；纸面账户无闭合交易时胜率/盈亏比为空——均在界面标注，不再以空白或 0 误导。

## 七、板块趋势与题材炒作雷达（2026-10-29 晚）

### 数据层：新增 /api/themes

| 端点 | 内容 |
|---|---|
| GET /api/themes/overview | 板块趋势 TOP12（今日/5日/20日/60日、上涨占比、阶段、龙头）+ 生肖字辈雷达 + 自主发现字 + 数据说明 |
| GET /api/themes/board/{code} | 板块成分股（按今日涨幅排序，含价格/涨幅/成交额） |
| GET /api/themes/char/{char} | 字辈成分股（如“羊”→ 三羊马、水羊股份） |

实现：`server/routers/themes.py`。数据源两条：

1. 本地东财板块快照（`data/sector_map.json` 496 个板块/5657 只股票索引、`sector_periods.json` 5/20/60 日收益）——
   历史收益截至快照时间（当前 2026-10-16，界面明示日期）；
2. 新浪 A 股全市场实时快照（5576 只，名称/涨跌幅/成交额/换手率），56 页并发抓取，服务端缓存 180 秒，
   并在启动时后台预热（`warm_themes_cache`），首开不再等 5–6 秒。

### 板块趋势算法

- 今日涨跌 = 板块成分股实时涨跌幅均值；上涨占比 = 成分股上涨家数占比；
- 趋势分 = 5日×1.6 + 20日×0.9 + 60日×0.2 + 今日×2.0 + (上涨占比-50)×0.25；
- 阶段：主升/发酵（今日≥4.5% 且 5日≥5% 且上涨占比≥65%）、趋势加速（5日≥8% 且 20日≥10%）、
  启动（今日≥2.5% 且 5日<4%）、分歧（5日>0 但今日<0.5% 且上涨占比<55%）、退潮（5日≤-3% 或 今日≤-2.5% 且上涨占比<40%）、震荡。

### 题材炒作（字辈雷达）

- 固定生肖字：羊/马/龙/蛇/兔/牛/虎/猴/鸡/狗/猪/鼠；
- 自主发现：在“涨幅≥5% 的高位股”中统计汉字聚集度，与全市场基准比较取 lift，lift≥2.2 且命中≥2 的字自动进入雷达；
- 每个字辈给出：成分股数、平均涨幅、上涨占比、准涨停数、成交额、热度（0–100）、阶段（发酵/走强/观察/退潮）、龙头股。

### 交互

- 板块行点击 → 浮层显示成分股 → 点个股 → 进入策略选股；
- 字辈卡 / 自主发现行点击 → 浮层显示该字成分股 → 点个股进入策略选股；
- 决策台 10 张卡片：结论、世界局势、市场温度、资金板块、**板块趋势**、**题材雷达**、持仓风险、事件情报、复盘、决策卡。

### 已知限制

- 东财 push2 在本机网络被阻断，板块历史收益只能用本地快照（日期已标注），每日更新需在有网时重建快照；
- 字辈基于股票名称文本匹配（含北交所），涨停用 ≥9.7% 近似；
- 阶段与热度是启发式指标，仅用于复盘与题材观察，不构成买卖建议。
