# DAPENG Alpha 产品战略与路线图（2026 Q4 版）

> 版本：v1.0 · 2026-10-30
> 状态：生效中（本文件是产品定位、路线与取舍的唯一战略事实源；与 `product-roadmap-2026.md` 冲突时以本文为准）

## 一、一句话定位

**DAPENG Alpha = 个人 A 股「决策操作系统」：把盘前计划、盘中纪律、盘后复盘串成一条可执行的闭环，用可信数据和可解释规则替代盯盘焦虑。**

它**不是**荐股软件、不是跟单社区、不是又一个选股器。选股/选板块只是输入，真正的产品是「决策与复盘」。

## 二、为什么做它（问题定义）

个人投资者真正缺的不是"更多指标"，而是：

1. **信息过载**：行情、资金、题材、外盘、新闻分散在十几个 App，盘前 10 分钟拼不出结论；
2. **决策无记录**：凭感觉买卖，事后无法回答"当时为什么这样判断"；
3. **复盘无闭环**：亏损归因于"运气/大盘"，没有可迭代的改进；
4. **工具不可控**：数据源说断就断、面板说空就空、云端/本地说不清，关键时刻掉链子。

DAPENG 的答案是：**一个自己完全掌控、数据可降级、决策有模板、复盘有留痕的系统。**

## 三、目标用户与核心场景

| 维度 | 定义 |
|---|---|
| 主用户 | 你本人：有稳定学习/工作时间、以 A 股为主、资金规模个人级、愿意花 10–20 分钟做纪律化复盘 |
| 使用设备 | 宿舍 Windows 电脑（主力计算/数据）+ 手机（查看/推送） |
| 盘前 5 分钟 | 看决策台结论（攻守/仓位上限）、隔夜外盘、当日题材与观察板块，生成交易计划 |
| 盘中 | 只看纪律与异动提醒，不频繁操作；盯盘任务/通知 |
| 盘后 10 分钟 | 自动复盘（权益/回撤/交易/偏差），写明日计划，沉淀到经验库 |
| 未来扩展 | 小团队/朋友共用（只读分享）、策略研究、模拟盘对照 |

## 四、价值主张与护城河

### 4.1 三层价值

1. **数据可信层**：多源适配 + 健康检查 + 降级标记 + 本地缓存 + 通达信离线数据；
2. **决策闭环层**：决策台（盘前/盘中/盘后）+ 交易计划 + 风控约束 + 复盘模板；
3. **复盘进化层**：留痕、归因、经验库、策略迭代（后续 Agent 化）。

### 4.2 护城河（别人难复制的点）

- **数据工程耐心**：腾讯/新浪/东财/本地 TDX 多源切换、熔断、缓存、质量标记——这是长期踩坑积累，不是界面能抄的；
- **决策流程资产**：决策卡、检查清单、复盘口径、风控规则，属于个人方法论沉淀；
- **本地优先的可控性**：数据、代码、账户都在自己手里，不依赖第三方 SaaS 的存亡；
- **极低边际成本**：本地/一台轻量云即可运行，不烧钱买流量。

## 五、竞品参考：ai1foo「股先生」（学习与取舍）

参考站点：`https://ai1foo.com/aistock/stock-agent/`（2026-10-30 用浏览器实测）

它做对的（值得借鉴）：

| 能力 | 说明 | 我们的映射 |
|---|---|---|
| 自然语言 → 可执行任务 | "把投资想法交给它执行"：识别目标→选工具→调专家→出报告→可设定时 | P2 做「一句话任务」（复盘/盯盘/筛选） |
| 多专家角色 | 巴菲特价值、彼得林奇成长、索罗斯宏观等视角 | 决策台增加「多视角会诊」卡片 |
| 盘前内参 | 隔夜消息/外盘/宏观一键汇总 | 决策台已有世界局势，补"盘前内参"摘要 |
| 集合竞价/技术战法 | 竞价异动、九转、多指标共振 | 作为策略库/提醒接入，不堆功能 |
| 定时任务 + 通知中心 + 盯盘 | 任务化监控与推送 | P2：已有 automation/alerts 基础，补统一任务中心 |
| AI 模拟盘排行榜 | 多模型同台竞技、对基准 | 可做「策略/模型模拟盘」页，验证而非荐股 |

它不适合照搬的：

- **不做荐股/跟单/收益承诺**：合规与信任风险高；
- 不追求"1000+ 功能"的堆砌：个人系统要的是闭环与稳定；
- 不把核心决策交给不透明黑箱：我们的结论必须可解释、可回测、可复盘。

**结论：学它的"任务化/专家化/基准化"，不学它的"大而全/流量化"。**

## 六、路线图（2026 Q4 → 2027 H2）

### P0 · 本地系统稳定（2026 Q4，进行中/大部分完成）

- [x] 决策台（盘前/盘中/盘后）与题材雷达、板块趋势
- [x] 数据源直连修复（NO_PROXY）、多源健康检查 `/api/data-sources/health`
- [x] 手机简报 `mobile.html`、邮件推送脚本、远程访问文档
- [x] 通达信本地 vipdoc 读取（离线历史数据，待安装客户端）
- [ ] 数据源健康面板可视化、异常自动告警
- 验收：连续 5 个交易日，盘前决策 + 盘后复盘不中断。

### P1 · 云化与多端（2027 Q1）

- 轻量云服务器 24×7 部署（Linux + systemd + Caddy/Tailscale）
- 手机 PWA（可添加到桌面、离线缓存、推送）
- 数据源：Tushare（基本面/日线）作为可选主源，腾讯/新浪实时，东财数据中心补龙虎榜/要闻
- 备份与恢复自动化（已有 backup 模块迁移到云）
- 验收：人在课室可实时查看；断网恢复后自动补数；月成本 ≤ ¥100。

### P2 · Agent 化投研任务（2027 Q2）

- 一句话 → 任务：`盘后复盘`、`盯住半导体异动`、`对比白酒估值`、`回测均线策略`
- 多专家视角会诊（价值/技术/宏观/风控），输出结构化报告
- 任务中心：定时、通知、失败重试、历史记录
- 模拟盘/策略对照（对沪深300基准），只做验证不做荐股
- 验收：80% 的日常研究需求可通过任务完成；任务成功率 ≥ 95%。

### P3 · 策略工厂与可选商业化（2027 H2）

- 策略库/因子库、回测归因、组合优化、风险预算
- 可选的轻商业化：只读分享、订阅报告（严守合规，不承诺收益）
- 验收：策略从想法到回测上线 ≤ 1 天；系统可被 1–3 人稳定使用。

## 七、关键指标（北极星与护栏）

| 类型 | 指标 | 目标 |
|---|---|---|
| 北极星 | 每周完成「盘前决策 + 盘后复盘」的交易日数 | ≥ 4/5 |
| 数据 | 关键数据源可用率（critical） | ≥ 99% |
| 数据 | 面板"降级/缓存"误报率（把旧数据当实时） | 0 |
| 决策 | 交易计划执行率（计划 vs 实际） | ≥ 80% |
| 复盘 | 复盘留痕覆盖率（有交易必复盘） | 100% |
| 工程 | 服务可用率、备份成功率 | ≥ 99% / 100% |
| 成本 | 月度云+数据成本 | ≤ ¥150 |

## 八、资源与预算（现实约束）

- 云服务器：轻量 2C2G 约 ¥50–100/月（新用户促销可 ¥99/年，见 `docs/40-ops/CLOUD-DEPLOYMENT.md`）；
- 数据：Tushare 积分制（基础免费/低费），东财/腾讯/新浪免费但有限流；
- 时间：每天盘前 10 分钟 + 盘后 15 分钟，周末 1 小时维护；
- 原则：**先闭环，后智能；先稳定，后扩展；不为功能而功能。**

## 九、风险与对策

| 风险 | 对策 |
|---|---|
| 数据源被封/改协议 | 多源适配 + 健康检查 + 本地 TDX + 缓存降级；关键源故障有替代 |
| 合规风险 | 不荐股、不代客理财、不承诺收益；只做工具与复盘 |
| 单人维护精力有限 | 文档先行、自动化巡检、能用现成轮子不自研 |
| 过度拟合/自欺 | 复盘看过程指标（执行率/纪律）而非只看收益；模拟盘对照基准 |
| 云服务器网络限制 | 先买 1 个月实测腾讯/新浪/东财/Tushare 可达性，再决定长期 |

## 十、决策原则（写死，避免摇摆）

1. **数据可复现 > 功能数量**：任何指标必须能说明来源、时间、口径；
2. **闭环 > 智能**：没有盘前/盘后闭环前，不做花哨 AI；
3. **本地优先，云为备份**：本地是主控，云负责 24h 在线与推送；
4. **一切改动写文档**：战略、架构、数据源、运维、复盘都要落盘并可检索；
5. **不荐股、不承诺收益**：产品价值是"让你做更好的决策"，不是"替你赚钱"。
