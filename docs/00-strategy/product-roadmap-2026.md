## 〇、北极星目标（本系统的唯一衡量标准）

> 规划此前只有路线没有终点。本节补上终点——**所有排期、取舍、验收都以这一条为准绳**。

**目标陈述（2026 年 12 月 31 日前达成）**：

> **纸面交易账户在 90 天滚动窗口内持续跑赢沪深300，且每一笔交易 100% 可回溯。**

一句话：**先证明"规则+AI"能在纸面上稳定赚钱，再谈一切其他功能。**

### 衡量指标（验收口径）

| 维度 | 指标 | 达标线 | 数据来源（均已具备） |
|------|------|--------|---------------------|
| 收益 | 90 天纸面收益率 vs 沪深300 | ≥ 基准 +3pct | `paper_account` + 指数行情 |
| 风险 | 最大回撤 | ≤ 10% 且 ≤ 沪深300同期回撤 | 净值曲线 |
| 质量 | 胜率 / 盈亏比 | ≥ 55% / ≥ 1.5 | `signals` + 成交流水 |
| 过程 | 交易可回溯率 | 100%（每笔成交能查到当时策略信号+AI研判+风控快照） | 审计日志 |
| 习惯 | 周复盘报告 | 每周自动生成，连续不缺周 | 复盘系统（Phase 2） |

### 该目标明确排除的事项（防止跑偏）

1. **不追实盘盈利**——券商通道未接通且涉及合规，2026 年内实盘不在目标内；
2. **不追功能数量**——不能服务上述指标的新功能一律缓建；
3. **不做多用户/商业化**——单机自部署边界不变，先对自己负责。

### 对规划的反作用（目标驱动的优先级修正）

- **复盘系统从"P1 之一"提为"关键路径"**：没有它，北极星指标连仪表盘都没有；
- **配置 `DEEPSEEK_API_KEY` 提为 P0 前置**：当前未配置导致 AI 决策卡（核心价值）实际不可用，服务端一个环境变量即可解锁；
- **风控 2.0 与回撤指标绑定**：熔断/降仓规则的验收标准就是"90 天 maxDD ≤ 10%"；
- **策略超市化与胜率/盈亏比绑定**：回测对比矩阵的产出必须能解释"为什么这季度的胜率达标/未达标"。

## 一、系统定位

**一句话定位：面向个人投资者的 A 股量化决策辅助工作台** —— 用数据与规则替代情绪化盯盘，把"选股 → 验证 → 决策 → 复盘"收敛到一个界面内完成。

当前系统已具备的能力盘点：

| 模块      | 现状                                             | 成熟度 |
| ------- | ---------------------------------------------- | --- |
| 行情与 K 线 | KLineChart v10 双引擎（ECharts 兜底），120 根日 K + 副图指标 | 高   |
| AI 实时分析 | DeepSeek 增强决策卡（入场/止损/止盈/仓位/置信度）+ 内联摘要 + 大屏模式   | 高   |
| 板块分析    | 5/20/60 日板块排行与周期切换                             | 中   |
| 策略与回测   | 策略面板、双内置策略（MA 交叉 ATR、N 日突破）、回测门控               | 中   |
| 自动化交易   | M1-M3 后端（调度/风控/纸面撮合/网关）+ M4 前端四 Tab 浮层         | 中   |
| 通知告警    | 邮件通道 + 异动提醒                                    | 中   |

**差异化判断**：市面工具要么是纯行情软件（同花顺/东财），要么是重平台量化框架（vn.py/QMT）。本系统的生态位是**轻量级个人决策台**——不追求机构级执行，而是把"AI 研判 + 规则化风控 + 纸面验证"做成年内可信赖的个人驾驶舱。

## 二、目标用户群体

1. **核心用户（当前即是你本人）**：有本职工作、用业余时间做 A 股短线/波段的个人投资者。痛点：盯盘时间碎片化、决策凭盘感、缺少交易记录与复盘。
2. **次级用户（半年内可触达）**：亲友圈与小型投资社群中"想用量化但不会写代码"的用户。需求：开箱即用、明确的买卖建议呈现、风险提示。
3. **不服务的用户**：高频/套利交易者（延迟与合规不匹配）、机构（功能深度不足）。

用户画像决定了产品取向：**可读性 > 信息密度 > 功能数量**，这正是本次界面优化的主线。

## 三、核心功能价值

1. **AI 研判的可解释化**：不只给"买入"结论，而是同时给出置信度、入场区间、止损、双止盈位与仓位建议——把 AI 从"黑盒预测"变成"可核验的决策草稿"。
2. **规则先于直觉**：所有自动交易必须先回测、过风控门控（gate_state 状态机）、纸面账户验证后才能进入实盘——这是系统最值得长期投入的信任基石。
3. **一屏闭环**：选股、K 线、板块、AI、回测、自动化在同一仪表盘内，个人用户的"工具切换成本"趋近于零。

## 四、阶段性发展规划

### Phase 1（1-2 个月）：把"看得清"做完 —— P0 体验收尾

优先级 P0，均为低风险高确定性工作：

- [x] K 线界面视觉与布局优化（本次完成：配色/网格/最新价标签/十字线/窗格高度预算）
- [x] AI 分析内联摘要 + 全屏大屏模式（本次完成，含浮层几何与网格填充修复）
- [x] 移动端 390px 全链路适配（K 线卡 508px 未塌缩、AI 大屏单列退化，双视口验证通过）
- [ ] 大屏模式补充：技术指标明细表（KDJ 的 K/D/J 数值、MACD 柱值）、历史研判对比
- [ ] 异常兜底统一：AI 缺失占位说明已完成（v5.1）；行情源断流占位与重试文案待做
- [x] **P0 前置：配置 `DEEPSEEK_API_KEY` 并重启服务**（2026-10-07 完成：旧 key 账户 402 欠费，换用有效 key；AI 决策卡已实测上线，另修复 analyze 对异常 K 线条目的防御过滤）

### Phase 2（3-4 个月）：把"信得过"做实 —— P1 交易闭环（北极星关键路径）

- [x] **P1 · 复盘系统（关键路径，最先做）**：✅ MVP 已于 2026-10-07 交付——`/api/review/summary|equity|weekly` 三端点（胜率/盈亏比/maxDD/90天超额 vs 沪深300/可回溯率/逐项达标判定）+ 自动化中心"复盘"Tab（北极星目标卡 + 净值 vs 基准曲线 + 周复盘叙述）+ 每日权益快照自动累积。后续迭代：交易按月归因、复盘报告邮件推送
- **P1 · 策略超市化**：策略参数可视化配置 + 回测对比矩阵（≥3 策略并排），让"先回测再上线"成为默认动作；产出必须能解释胜率/盈亏比的来源
- **P1 · 风控 2.0**：日内最大亏损熔断、连续亏损降仓位、单策略回撤限额；验收标准 = 90 天 maxDD ≤ 10%
- **P1 · 通知升级**：企业微信/Telegram 通道（现有邮件通道偏慢），关键节点（成交/止损/熔断）分级推送

### Phase 3（5-8 个月）：把"用得久"做深 —— P2 智能与扩展

- **P2 · AI 复盘助手**：用 LLM 对周报做归因分析（"本周亏损集中于追高打板"类结论）
- **P2 · 多周期联动**：日线主图 + 60/30 分钟子图联动，支持波段调仓场景
- **P2 · 数据资产化**：本地化存储全量自选股行情快照，为自定义因子回测供数
- **P2 ·（可选）多账户**：纸面 ↔ 实盘影子对照，量化"执行偏差"

## 五、长期演进路线（12 个月+）

```
决策辅助工具 ──→ 个人量化操作系统 ──→ 可分享的半托管服务
（现在）          （Phase 2-3 完成后）     （远期，谨慎）
```

- **12 个月愿景**：所有自动交易决策 100% 可回溯（每次下单能查到当时的 AI 研判、策略信号与风控快照）——"可审计"是个人量化系统与炒股软件的本质分界。
- **商业化边界**：若未来对外提供服务，需评估投资顾问牌照合规问题；在此之前坚持"单机/自部署、无代客理财"的边界。
- **技术债清单**：根目录 `dashboard.html` 冗余副本清理、`strategies-ui.js` 与 `app.js` 职责再切分、行情源双通道（腾讯 + 备用）热切换。

## 六、本次优化与规划的关系

本次三项优化全部落在 Phase 1：

1. **K 线界面优化** = Phase 1 "看得清"的主体工程（图表元素清晰度 + 信息可读性）；
2. **AI 大屏模式** = Phase 1 "AI 研判可解释化"的呈现升级，后续技术指标明细直接在大屏内扩展；
3. **本文档** = 规划基线，Phase 2 起按 P1/P2 优先级排期，每季度回顾一次。
