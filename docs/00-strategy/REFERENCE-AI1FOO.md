# 竞品参考：ai1foo「股先生」（2026-10-30 实测）

> 用途：借鉴其产品设计与数据对接思路，明确「学什么、不学什么」。
> 目标站点：<https://ai1foo.com/aistock/stock-agent/>（浏览器实测；页面为 React SPA）

## 一、它是什么

「把投资想法交给 AI 执行」的通用投研 Agent 平台：自然语言对话 → 选择工具/专家 → 输出报告 → 可设为定时任务；同时提供选股、财务分析、回测、盯盘、通知、大盘云图、AI 每日筛股等模块。

## 二、值得借鉴的设计

| 设计 | 观察 | 我们的落地 |
|---|---|---|
| 任务五步法 | 识别目标 → 选择工具 → 调用专家 → 输出报告 → 可设定时 | 决策台任务化（P2）：一句话生成盘后复盘/盯盘任务 |
| 专家角色 | 巴菲特价值、彼得林奇成长、索罗斯宏观等视角 | 决策台增加「多视角会诊」：价值/技术/宏观/风控 |
| 盘前内参 | 隔夜外盘、消息、宏观一键汇总 | 已有「世界局势」卡，补「盘前 60 秒摘要」 |
| 集合竞价/战法 | 竞价异动、九转、多指标共振 | 作为提醒/策略库接入，保持少而精 |
| 定时任务 + 通知中心 + 盯盘 | 保存条件为可执行监控任务 | 复用现有 automation/alerts，统一任务中心 |
| AI 模拟盘排行榜 | 多模型各 ¥10 万、对沪深300基准、连续追踪 | 可做「策略/模型模拟盘」对照，验证而非荐股 |
| 数据源线索 | 代码中出现 `stockApi`、`useTradingData`、`callTushareApi`、`baiduFinanceApi` | 我们的数据平台：Tushare（基本面）+ 百度/腾讯/新浪（补充）+ 本地 TDX |

## 三、不照搬的部分

1. **不做荐股/跟单/收益承诺**：合规与信任风险高，且违背"决策工具"定位；
2. 不追"1000+ 功能"：个人系统要闭环与稳定，功能越多维护越重；
3. 不把核心决策交给黑箱：结论必须可解释、可回测、可复盘；
4. 不依赖单一第三方 SaaS：数据源要可替换、可降级。

## 四、对我们最有价值的三点

1. **任务化**：把"分析"变成可保存、可定时、可通知的任务，而不是一次性对话；
2. **专家化**：同一标的用不同方法论会诊，降低单一视角偏差；
3. **基准化**：任何策略/模型都要有基准对照（沪深300/等权），避免自嗨。

## 五、差距与下一步

| 差距 | 现状 | 计划 |
|---|---|---|
| 自然语言任务 | 无 | P2：接入 LLM + 任务编排（复用 automation 任务/通知） |
| 多专家会诊 | 无 | P2：专家提示词模板 + 结构化输出 |
| 统一任务中心 | automation 分散 | P2：任务列表/定时/重试/通知 |
| Tushare 基本面 | 未接 | P1：加 `TUSHARE_TOKEN` 适配器 |
| 模拟盘对照 | 有纸面账户，无对照榜单 | P3：策略/模型基准榜 |

## 六、结论

ai1foo 证明「任务化投研」是可行方向，但它的商业形态是流量平台；我们保持**个人决策 OS** 的克制：先闭环、再智能，先可信、再丰富。
