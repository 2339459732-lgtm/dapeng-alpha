## 1. 总体原则

1. **稳定优先**：保留 FastAPI + 原生 HTML/JavaScript + ECharts 架构，不直接迁入 React/Vue/Streamlit 等第二套前端框架。
2. **能力借鉴，不做整仓复制**：借鉴优质项目的数据分层、组合分析、风险指标、策略评估和图表交互；新增实现保持与当前代码一致。
3. **许可证优先**：MIT、Apache-2.0 可作为设计与实现参考；AGPL-3.0 仅作产品与指标参考，不复制代码；无明确许可证的仓库不引入代码。
4. **数据源可降级**：腾讯行情继续作为实时主链路；后续可选接入 AKShare，但必须具备超时、缓存、字段映射、熔断和原数据源回退。
5. **不接真实交易**：模拟持仓、策略回测和风险评估只用于研究，不触发券商下单。
6. **渐进交付**：每阶段都必须通过 Python/JavaScript 语法、接口响应、空数据、上游失败和页面回归检查。

## 3. 当前系统基础

当前项目已经具备：

- 腾讯实时行情、K线缓存、周期切换与实时更新；
- 条件选股、全市场扫描、量比/换手率/PE 条件；
- 板块、资金流、龙虎榜、研报、北向资金、新闻；
- RSI、MACD、KDJ、布林带、ATR、最大回撤、波动率与 VaR；
- `server/routers/strategy_lab.py`：趋势跟随、放量突破、均值回归三类轻量历史评估；
- `static/js/portfolio.js`：本地模拟持仓雏形，但尚未接入页面、缺少样式和严谨校验；
- 自选股、股票对比、价格预警和本地持久化。

因此不需要重建系统，重点是激活已有模块、补齐风控与稳定性，再逐步扩展数据源。

## 4. 分阶段实施

### P0：稳定基线与已有模块激活

目标：在不新增后端依赖的情况下形成可用闭环。

- 将“策略实验室”“模拟持仓”接入 K 线功能标签；
- 策略实验室调用 `/api/strategy-lab/evaluate`，展示市场状态、三策略收益/回撤/胜率/夏普、资金曲线和风险建议；
- 完善模拟持仓：买卖数量校验、不可超卖、现金/市值/累计盈亏、止损提示、交易记录、导出与清空；
- 修正持仓今日盈亏公式，使用昨收推导；
- 所有动态内容转义，避免本地持久化数据污染 DOM；
- 页面切换按需渲染，后台标签页不持续高频刷新。

验收：无持仓、错误输入、缺行情、刷新页面、移动端均可用；原策略、行情和图表不回归。

### P1：QuantStats 风格组合风险中心

目标：让模拟持仓从“列表”升级为“组合风险面板”。

- 组合总收益、当日收益、夏普、波动率、最大回撤；
- 权重分布、行业集中度、单股集中度、止损覆盖率；
- 组合净值曲线与回撤曲线；
- 风险提示：单股过重、无止损、亏损穿越止损位、数据缺失；
- 计算口径和免责声明常驻展示。

实施方式：先用现有 K 线与本地交易记录原创计算，不引入 QuantStats 包。

### P2：AKShare 可选数据适配层

目标：扩展财务、公告、股东、估值和板块历史数据，但不影响实时主链路。

- 新建 provider 接口，统一 `code/name/time/source/stale` 字段；
- AKShare 作为可选依赖和补充源；
- 每个接口设置超时、缓存 TTL、字段校验、熔断和腾讯/现有接口回退；
- 前端标记数据来源、更新时间、是否缓存或过期；
- 不在请求线程执行大批量同步抓取。

验收：未安装 AKShare 时系统照常运行；上游失败时返回明确降级状态，不阻塞页面。

### P3：新闻情绪与事件中心

目标：借鉴 FinGPT 的研究流程，不默认部署大型模型。

- 新闻去重、时间衰减、来源标记；
- 正面/中性/负面聚合与置信度；
- 财报、监管、股东变动、重大合同等事件标签；
- 情绪与价格走势联动展示；
- AI 不可用时回退为关键词规则与现有新闻列表。

### P4：高级回测与复盘

目标：扩展现有策略实验室，而非引入 AGPL 代码。

- 参数化 MA、突破、均值回归；
- 交易成本、滑点、涨跌停和最小交易单位；
- 基准指数对比、滚动收益和交易明细；
- 防前视偏差、最小样本量提示；
- 批量策略比较放后台任务执行。

## 6. 稳定性保障

- API：8–12 秒超时、300 秒策略结果缓存、明确 `ok/data/message`；
- 前端：请求序号避免旧请求覆盖新股票；图表销毁与 resize 防泄漏；
- 数据：NaN/Infinity/零成本/缺行情全部兜底；
- 存储：LocalStorage 读取异常恢复为空数据，写入失败给提示；
- 性能：模块按 Tab 懒加载，不新增全局高频轮询；
- 安全：所有动态字符串转义，不使用远程 CDN 新依赖；
- 回归：Python 编译、JS `node --check`、HTML 资源、关键接口和 HTTP 200。
