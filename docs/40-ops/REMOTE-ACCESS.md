# 远程访问与离线运行（宿舍电脑 / 手机热点场景）

> 背景：电脑在宿舍，唯一网络是手机热点；人去课室后手机离开，电脑断网 —— 系统无法取数、无法把决策同步到手机。
> 这是**网络接入问题**，不是软件缺陷：任何程序都无法在断网时持续获取行情。本文给出可落地的三条路线与已经实现的兜底能力。

## 一、先给电脑一条“自己的网”（必须二选一）

| 方案 | 成本 | 稳定性 | 说明 |
|---|---|---|---|
| **宿舍宽带 / 校园网** | 低（已有则 0） | 最高 | 最推荐。校园网若需网页认证，可写自动登录脚本保活 |
| **4G/5G 路由器 + 流量卡**（或旧手机长期插卡放宿舍） | 约 30–100 元/月 | 高 | 电脑连它，手机随身带走互不影响；选大流量卡 |
| 把系统迁到云服务器（轻量 VPS） | 约 30–60 元/月 | 最高（24×7） | 不依赖宿舍电/网；但本地通达信数据、部分境内接口需重新适配 |

**不建议**：让电脑继续依赖“随身热点”。手机离开 = 断网，这是物理约束，无法用软件绕开。

## 二、电脑有网后，手机怎么访问（二选一）

### 方案 A：Tailscale（推荐，穿透 CGNAT，不需要公网 IP）

1. 电脑与手机都安装 Tailscale，登录同一账号；
2. 电脑端运行服务（已监听 `127.0.0.1:8900`，需允许局域网/Tailscale 访问：启动时把 `HOST` 改为 `0.0.0.0` 或在 Tailscale 里用 `tailscale serve`）；
3. 手机浏览器打开 `http://<电脑Tailscale IP>:8900/mobile.html`。

> 注意：dashboard 目前无登录鉴权，**不要**直接暴露到公网；Tailscale 是私有网络，符合要求。

### 方案 B：Cloudflare Tunnel（有域名时更优雅）

```
cloudflared tunnel --url http://127.0.0.1:8900
```
快速隧道会生成临时公网地址；长期使用建议命名隧道 + Cloudflare Access 登录保护。
若没有域名/账号，优先 Tailscale。

## 三、手机端页面（已实现）

- `http://<电脑地址>:8900/mobile.html` —— 移动端决策简报：
  今日结论（风险指数/攻守/仓位上限）、市场温度、题材雷达（羊/马等）、板块趋势、事件情报、复盘摘要；
- 60 秒自动刷新；接口失败时显示**本机缓存**并标注“离线缓存”；
- 顶部有「完整版」入口，可打开桌面版 dashboard。

## 四、主动推送（电脑有网时，把决策发到手机）

已提供 `scripts/push_decision.py`：汇总大盘结论、涨跌分布、情报、题材、板块、账户，生成文本并可通过 QQ 邮箱（`.env` 已配置 SMTP）发送到手机邮箱。

```powershell
python scripts\push_decision.py           # dry-run，只打印
python scripts\push_decision.py --send    # 发送到配置邮箱
```

定时任务示例（每天 08:40 盘前、15:10 盘后各一次）：

```powershell
schtasks /Create /TN "DAPENG-盘前推送" /TR "python dapeng-water/scripts\push_decision.py --send" /SC DAILY /ST 08:40 /F
schtasks /Create /TN "DAPENG-盘后推送" /TR "python dapeng-water/scripts\push_decision.py --send" /SC DAILY /ST 15:10 /F
```

## 五、离线兜底（断网时系统还能做什么）

1. **通达信本地数据**：已实现 `/api/tdx/status`、`/api/tdx/kline`，读取 `vipdoc` 下 `.day/.lc1/.lc5` 文件。
   安装通达信金融终端 → 盘后数据下载 → 设置 `TDX_HOME` 指向安装目录即可；断网时仍可用本地历史K线做分析。
   实测：TDX 公开行情服务器（7709）当前协议握手异常/被网络限制，因此优先用「本地盘后数据」方式；
2. **决策台缓存**：大盘/题材接口失败时展示最近一次成功快照并明确标注，不会假装实时；
3. **mobile.html 缓存**：手机页面在断网/服务不可达时显示上一次结果；
4. 系统日志与 `/api/health` 可用于判断是网络问题还是数据源问题。

## 六、推荐组合（成本最低且稳）

1. 宿舍办一条宽带或买一张大流量卡 + 4G 路由器（电脑 24h 在线）；
2. 电脑装 Tailscale，手机装 Tailscale；
3. 手机收藏 `http://<tailscale-ip>:8900/mobile.html`；
4. 配置每天 08:40 / 15:10 邮件推送；
5. 通达信装好并下载盘后数据，作为断网/限流时的备用历史数据源。

这样：人在课室 → 手机随时看决策；电脑断网 → 手机仍能收推送（推送依赖电脑在线，因此第 1 步是前提）；行情源被限 → 通达信本地数据兜底。
