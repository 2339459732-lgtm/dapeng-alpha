# 打板复盘：数据要求与生成方式

> 落地日期 2026-11-03 ｜ 代码：`scripts/review/parse_statement.py`、`scripts/review/build_review.py`
> 定位：把**某个交易者的成交流水**变成逐日可对照的打板复盘（Markdown 日报 + Excel 台账 + HTML 看板）。

---

## 一、需要提供什么

一份成交明细（CSV / XLSX / XLS 都行），券商导出、同花顺/通达信「成交记录」导出均可。
最少需要这 6 列，其余可选：

| 列 | 必需 | 说明 | 可接受的别名（自动识别） |
|---|---|---|---|
| 成交日期 | ✅ | `2026-10-30` / `20261030` / 带时间 | 发生日期、交易日期、日期 |
| 成交时间 | 建议 | `09:31:12`；缺时间也能跑，但入场时段分析会缺失 | 发生时间、委托时间、时间 |
| 证券代码 | ✅ | 6 位数字即可，自动补 `sh/sz/bj` | 股票代码、代码、证券编码 |
| 买卖标志 | ✅ | 含「买/卖」或 B/S | 买卖方向、操作、业务名称 |
| 成交价格 | ✅ | 元 | 成交均价、成交价、价格 |
| 成交数量 | ✅ | 股 | 成交量、成交股数、数量 |
| 成交金额 | 可选 | 元；缺省按 价格×数量 | 发生金额、金额 |
| 佣金 / 印花税 / 过户费 / 其他费 | 可选 | 有则精确计入；**全缺时按规则估算并在报告标注** | 手续费、交易手续费 |
| 板型 | 可选 | 首板 / 二板 / 三板…；**这是打板属性的唯一可靠来源** | 板数 |
| 止损价 / 止盈价 | 可选 | 计划值；有它才能评估「按计划执行」 | 计划止损、目标价 |
| 备注 / 成交编号 | 可选 | 原样带到明细里 | 摘要、委托编号 |

> 缺「板型」不会阻断，但报告里会标「未标注」——**不做价格猜测**，因为这会把「追高」误判成「打板」。
> 缺费用列时会估算：佣金万 2.5（最低 5 元）+ 印花税千 0.5（仅卖出）+ 过户费十万分之一，并在报告标注「费用为估算」。

## 二、两条命令

```bash
# 1) 解析成统一字段（列名映射、方向归一、代码补前缀、费用补齐）
python scripts/review/parse_statement.py --input 交割单.xlsx
#   → data/review/trades_normalized.csv

# 2) 生成三种复盘
python scripts/review/build_review.py --trades data/review/trades_normalized.csv
```

输出：

```
reports/daily/打板复盘_2026-10-30.md        逐日复盘（概览/逐笔买入/回合/交割单/风格小结）
reports/打板复盘_总览.md                     跨日汇总 + 风格画像 + 策略有效性
reports/打板复盘台账_2026-10-30_2026-11-03.xlsx   5 个 sheet：成交明细/逐笔回合/每日汇总/风格统计/口径说明
reports/打板复盘_2026-10-30_2026-11-03.html       自包含看板（离线可开，无外链）
```

验证管线是否正常：`--demo` 会跑一遍示例数据，产物文件名带 `_DEMO`，页头有「示例数据」横幅。

## 三、口径（报告里也会写明）

| 项 | 口径 |
|---|---|
| 回合配对 | 按标的 FIFO：卖出优先冲抵最早批次；卖出多于持仓时不硬配（数据缺口会暴露） |
| 净盈亏 | （平仓价 − 开仓价）× 数量 − 买卖双边费用 |
| 收益率 | 净盈亏 / 开仓成本 |
| 费用分摊 | 买入费用按数量摊到各平仓批次；卖出费用按本次卖出数量摊 |
| 未平仓 | 只计持仓，不计盈亏 |
| 离场判定 | 有计划的先比计划：≤止损 →「止损触发」；≥止盈 →「止盈触发」；落在区间内 →「区间离场」；完全没计划才按 ≤−5% / ≥+7% 归类并标「未设计划」 |
| 计划执行率 | 离场落在计划框架内（触发或区间）的比例 |
| 入场时段 | 9:30-10:00 / 10:00-10:30 / 10:30-11:30 / 13:00-14:00 / 14:00-14:30 / 尾盘 |

## 四、能看出什么（风格维度）

- **选股偏好**：市场分布（沪/深/创/京）、板型分布、ST 占比（名称含 ST 时在备注里标注）
- **入场时机**：时段分布 + 首板/连板占比
- **仓位分配**：单笔金额 P25/P50/P75 与最大值、单日买入金额
- **加减仓节奏**：同一交易日同一标的多次买入的次数（打板加仓 vs 一次性建仓）
- **离场逻辑**：止损触发 / 止盈触发 / 区间离场 / 未设计划 的分布
- **有效性**：胜率、盈亏比、单笔期望、盈利因子、累计已实现盈亏曲线

## 五、已知边界

1. **打板属性依赖「板型」列**：没有该列就只标「未标注」，不用价格反推，避免把追高当打板。
2. **不判断「是否封板/炸板」**：需要当日分时与封单数据，当前流水里没有；需要时另接行情源。
3. **T+1 不做强制校验**：A 股当日买入不可卖出；若流水出现当日买卖同标的，会按流水配对并在数据校验里暴露，而不是替用户改数。
4. **费用估算**：缺费用列时按市场规则估算，与券商实际扣费可能有几元差异。
